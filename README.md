# 个人智能财务规划计算器 (Finance Planner)

> **极简大号智能算盘 · 动态负债精算 · 50/30/20 资产配置 · 男女独立消费画像 · 零强制储蓄**  
> 基于 Python 原生移动跨平台框架 **Kivy** 打造，专为移动端单手操作优化。界面彻底告别传统表单杂乱框线的堆叠感，采用现代呼吸感软圆角卡片布局。

---

## 📱 核心产品理念与设计亮点

### 1. 🧮 极简“大号计算器”核心架构（拒绝强制储蓄）
* **数显大屏毫秒级联动**：顶部核心大屏即时呈现透明资金流：
  * **零负债时**：`到手 ￥4,200 − 支出 ￥3,700 = 结余 ￥500`
  * **有负债时**：动态扩展为 `到手 ￥4,200 − 还款 ￥800 − 支出 ￥2,900 = 结余 ￥500`
* **无压力理财心理学**：摆脱任何强行存钱的挫败感与枷锁，量入为出。结余为正自然沉淀，超支赤字即时变色提醒，数字清晰透亮。

### 2. 💳 首屏动态负债与欠费精算
* **首屏控制区即刻录入「月还负债」**：支持输入信用卡账单、花呗白条、房贷车贷、助学贷款或分期月供。
* **柔性动态反馈（告别僵硬教条）**：
  * **零负债**：显示绿色柔光 `零负债 无月供压力`；
  * **偿债率 $\le 20\%$**：评定为 `偿债率 XX%·负债压力轻微`（安全良性区间）；
  * **偿债率 $20\% \sim 40\%$**：评定为 `偿债率 XX%·月供适中可控`（建议预留流动备用金）；
  * **偿债率 $> 40\%$**：温和建议 `偿债率 XX%·负债偏重 建议优先还款`。
* **储蓄目标与智能规划动态避坑**：
  * 建议目标（黄金 20% 及 10%/20%/30% 胶囊）自动基于**扣除硬性还债后的净可支配资金**测算，避免高负债时给出不切实际的储蓄指标；
  * 「一键智能精算」算法优先保护负债偿还，并在剩余资金池中自动重新平摊开销，杜绝人为超支。

### 3. 👥 男女消费模型完全独立（解耦定制）
男女消费在生理属性、生活习惯和社交半径上存在客观差异，本系统彻底将两者解耦：
* **👩 女生版（品质与生活画像）**：
  * **生存刚需**：餐饮伙食、住房房租、交通通勤、通讯网络、医疗健康、**生理护理专属**（卫生巾/暖宫贴/调理）、**理发美发**（剪吹造型与烫染折算）；
  * **品质生活**：护肤美妆、穿搭鞋包、网购百货、茶饮甜品、社交聚会、旅游度假、萌宠生活、数码配件、自我提升、机动备用。
  * *切换至女生版时，界面自动智能渲染为浪漫樱粉色调。*
* **👨 男生版（科技与爱好画像）**：
  * **生存刚需**：餐饮伙食、住房房租、交通通勤、通讯网络、医疗健康、**理发修容**（洗剪吹/剃须护理）；
  * **兴趣生活**：数码科技、游戏电竞、运动健身、聚会社交、穿搭鞋服、网购日常、旅游户外、萌宠相伴、自我提升、机动备用。

### 4. 🎨 四大精致主题 & 护眼模式全域深度同步
* **晴空白 (Light)**：极简清透，适合日间高亮度环境；
* **樱粉浪漫 (Pink)**：女性专属，粉白辉映，温婉轻盈；
* **护眼暖阳 (Warm)**：**全域深度同步**为温润沙色 `(0.92, 0.88, 0.79)` 与暖灰褐文字 `(0.48, 0.39, 0.28)`。男女胶囊、锁定徽章、底部工具栏、弹窗取消键彻底剔除刺眼生硬白底与冷蓝混杂，夜间记账舒适柔和；
* **曜石极夜 (Dark)**：深邃黑金，暗光环境低功耗高对比。

### 5. 🔒 细目锁定保护 & 恩格尔阶梯智能平摊
* 每个开销项目均配备**锁定徽章微胶囊**（未锁 / 已锁）；
* 用户锁定的刚性项目（如固定房租、刚性通勤等）在点击「一键智能精算」时受到**绝对保护**；
* 未锁定项目根据不同收入阶段与恩格尔定律消费弹性自动重分配，杜绝预算倒挂。

### 6. 💾 JSON 自动持久化归档引擎 (`user_data.json`)
* 彻底摆脱手动“保存档案 / 载入档案”繁琐流程；
* 无论是修改收入、录入负债、调整细目、切换锁定状态还是改变主题风格，**后台毫秒级静默自动写入本地 JSON 沙盒**；
* 再次打开应用时，100% 自动还原最后一次的全部状态。

### 7. 🛠️ 四大高频场景化精算工具
* **餐饮与聚餐智能折算**：针对打工人/年轻人不吃早餐、周末聚餐下馆子、下午茶奶茶夜宵等真实生活场景，提供一键预设与细致测算；
* **学期开销平摊计算器**：针对在校大学生群体，将学杂费、住宿费按月平摊，测算最适月支配额度；
* **五险一金税后精算**：支持单位代缴、灵活就业与无社保模式，涵盖养老、医疗、失业、公积金与阶梯个税；
* **无限自定义预算项**：一键添加专属开销类别，无缝融入资金分配树。

### 8. 📊 纯净专业规划报告（无说教 · 无冗余安全提示）
* 移除了假大空的“数据安全备份提示”与说教式口吻；
* **四维客观专业分析**：
  1. **核心收支与负债总览**：税前薪资、实际到手、月度还债（附带偿债率与压力评估）、生活支出、净结余率；
  2. **资金分布架构**：对标国际经典的 50/30/20 资产配置模型，按「生存刚需」、「品质与兴趣」、「成长与结余」展现比例；
  3. **务实优化建议**：针对偿债压力、餐饮过高、网购冲动等真实数据给出温和理性的调整方向；
  4. **细目精算清单**：列明各分类实际金额、占比及锁定状态，支持**一键复制到手机剪贴板**。

### 9. 🔤 零乱码字库兼容保障
* 自带打包精简矢量中文字体 [`font.ttf`](file:///e:/Code/%E6%9D%82%E4%B8%83%E6%9D%82%E5%85%AB/android_app/font.ttf)；

## 🚀 运行与编译指南

### 方案 1：电脑端直接运行（开发与自测）
电脑已安装 Python 3 环境时，进入项目根目录直接运行：
```bash
python android_app/main.py
```
*窗口会自动限制为 `410 x 840` 手机标准竖屏比例，交互体验与真机完全一致。*

---

### 方案 2：利用 GitHub Actions 免费云端生成 APK（最推荐 · 免搭环境）
无需在本地配置庞大繁琐的 Android SDK/NDK 编译链，利用 GitHub 云端服务器可在 6~8 分钟内自动编译生成 64 位 APK：

1. **准备代码**：
   - 将 `android_app` 目录内的所有文件（或将 [`android_app.zip`](file:///e:/Code/%E6%9D%82%E4%B8%83%E6%9D%82%E5%85%AB/android_app.zip) 解压后的全部内容）推送到您的 GitHub 仓库。
   - 确保包含 `.github/workflows/build_apk.yml`、`buildozer.spec`、`main.py`、`font.ttf` 等。
2. **触发编译**：
   - 打开 GitHub 仓库页面，点击顶部的 **Actions** 标签。
   - 在左侧选择 **Build Android APK with Buildozer**，点击右侧 **Run workflow**。
3. **下载安装包**：
   - 等待约 6~8 分钟，流程运行完成后进入本次详情页。
   - 在最底部的 **Artifacts** 区域即可直接下载编译好的 `FinancePlanner-Android-APK.zip`。
   - 解压后把 `.apk` 文件传到安卓手机上即可安装运行！

---

### 方案 3：安卓手机本地直接运行（Pydroid 3 免打 APK）
1. 手机应用商店或酷安下载安装 **Pydroid 3**；
2. 打开 Pydroid 3，在 Pip 菜单中安装 `kivy`；
3. 将 `main.py`、`storage.py` 和 `font.ttf` 放在手机同一文件夹下；
4. 点击右下角运行按钮，即可直接在手机上全屏运行体验。

## 📊 核心计算模型与算法公式

1. **实际到手收入**：
   $$\text{到手净额} = \text{税前月薪} - \text{个人社保公积金} - \text{个税}$$
2. **净结余核心算式**：
   $$\text{月度结余} = \text{到手净额} - \text{月度负债还款} - \sum \text{生活开销}$$
3. **负债偿债率 (DTI)**：
   $$\text{偿债率} = \frac{\text{月度负债还款}}{\text{到手净额}} \times 100\%$$
4. **建议储蓄基准**：
   $$\text{净可支配资金} = \max(0, \text{到手净额} - \text{月度负债还款})$$
   $$\text{黄金建议储蓄 (20\%)} = \text{净可支配资金} \times 20\%$$
5. **智能精算支出资金池**：
   $$\text{可规划消费资金} = \max\left(0, \text{净可支配资金} - \text{已锁定刚需} - \text{目标储蓄}\right)$$
   *未锁定项目根据男女模型权重与恩格尔弹性系数加权平摊。*
